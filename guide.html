Installation guide

Getting your pack into Minecraft

Five simple steps. No mods to install — just OptiFine or CIT Resewn.

Installation steps

1
Install OptiFine or CIT Resewn
CIT (Custom Item Textures) requires either OptiFine (Java Edition) or the CIT Resewn mod for Fabric. Both are free. Download from their official sites.
2
Build your pack in the catalog
Browse the catalog, click into any model, choose your color variants and placements, and click "Add to pack." Repeat for as many items as you like.
3
Download your .zip
Head to Your Pack and click "Download .zip." A custom resource pack containing only your selected items will download to your computer.
4
Move it to resourcepacks
Drop the .zip directly into your Minecraft resourcepacks folder — do not unzip it.

Windows: Press Win+R → type %appdata%\.minecraft\resourcepacks
Mac: ~/Library/Application Support/minecraft/resourcepacks
5
Enable in-game
Open Minecraft → Options → Resource Packs. Your pack will appear on the left. Click the arrow to move it to the active side. Click Done.
6
Apply the CIT in-game
Place a base item (shown on each model page) in an anvil. Rename it to the exact code shown — for example ssc077a. The texture will apply automatically.

Understanding the anvil code

Every model has a unique code. When you rename the base item in an anvil to that code, OptiFine/CIT Resewn swaps the texture.

ssc
collection
+
077
model number
+
a
color
+
center
position (optional)
=
ssc077acenter
anvil name

If a model has only one position (no position code), just use the collection + number + color, e.g. ssc085a

Behind the scenes

Curious how Sims 4 furniture becomes a Minecraft model? Here's the full pipeline used to create every item in the catalog.

📦
Locate .package files
Find the Sims 4 .package file containing the furniture model and textures.
🎨
Export & posterize
Extract the mesh and textures from Blender. Posterize textures down to 32 colors for a pixel-art look.
🧊
Voxelize
Run .obj files through Drububu's online voxelizer to convert the smooth model into voxels.
🔷
Greedy meshing
Import voxel models into Blender using a voxel importer that applies greedy meshing to reduce face count.
⚙️
Convert to .json
Run scripts that turn the .obj files into Minecraft-compatible .json block model files.
🖼️
Bake textures
Bake and export the texture for each voxel model variant.
🧱
Polish in Blockbench
Import the .json and textures into Blockbench. Fix errors, adjust display settings, paint and refine.
📸
Screenshot & package
Screenshot each variant, then run scripts to generate .properties files and bundle everything into a resource pack.
