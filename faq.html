Yes. CIT (Custom Item Textures) is not a vanilla Minecraft feature. You need either OptiFine for Java Edition, or the CIT Resewn mod if you're using Fabric. Both are free and widely used. Download OptiFine from optifine.net and CIT Resewn from Modrinth.
Models are built and tested for Java Edition 1.20+. Most will work on older versions as long as OptiFine is installed and supports that version's pack format. Bedrock Edition is not supported — CIT is a Java-only feature.

Place the correct base item (shown on each model's page) into an anvil. Rename it to the exact code — for example, ssc077a for the Natural Floor Hammock Stand. The texture applies automatically as long as your pack is active.
Some models have multiple display modes — for example, the Floor Hammock Stand has a "default" position and a "center" position, which place the model differently relative to the block. If a model has position options, you add the position name to the end of the anvil code: ssc077acenter. If there's only one position, no suffix is needed.

All models are sourced from The Sims 4 community and converted into Minecraft CITs through a multi-step pipeline: textures are posterized, meshes are voxelized, greedy-meshed to reduce geometry, converted to .json, and polished in Blockbench. See the How it works page for the full breakdown.
